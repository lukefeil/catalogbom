# Catalog BOM

Catalog BOM is a lightweight FreeCAD workbench for spreadsheet-backed catalog
assignments, material information, and live part dimensions. It uses FreeCAD's
built-in APIs and Python's standard library.

## Documentation

The project maintains its detailed documentation in the main repository so it can
be updated and reviewed alongside implementation changes:

- [User Guide](https://github.com/lukefeil/catalogbom/blob/main/docs/userguide.md): installation, catalog format, commands, and troubleshooting.
- [Architecture](https://github.com/lukefeil/catalogbom/blob/main/docs/architecture.md): implementation, dependencies, and validation boundaries.
- [Project README](https://github.com/lukefeil/catalogbom/blob/main/README.md): development checks and repository setup.
